<tr>
<td>

### 🏗️ Retail Vision — Data Warehouse & BI

Sistema completo de Business Intelligence y Data Warehousing, desarrollado para la materia *Bases de Datos Avanzada*.

| Componente | Detalle |
|:--|:--|
| **Arquitectura** | Esquema estrella (*star schema*) con **4 tablas de hechos** interconectadas |
| **Pipeline ETL** | Implementado íntegramente en **PostgreSQL** |
| **Visualización** | Dashboards analíticos en **Tableau** |

<br>

**Hallazgos técnicos:**

```diff
- CROSS JOIN detectado: inflaba consultas de 1.000 → 1.000.000 de filas
+ Corregido con joins explícitos, rendimiento restaurado

- Dataset original: 90% de fallas de integridad referencial
+ Saneamiento completo del dataset antes de la carga al DW
```

</td>
