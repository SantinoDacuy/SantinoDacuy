## Proyecto destacado

### Retail Vision — Data Warehouse y BI
Desarrollado para la materia *Bases de Datos Avanzada*, este proyecto consiste en la creación de un sistema de Business Intelligence y Data Warehousing completo.
- **Arquitectura de Datos**: Diseño e implementación de un esquema estrella (*star schema*) con 4 tablas de hechos interconectadas.
- **Pipeline ETL**: Pipeline ETL robusto programado enteramente en PostgreSQL.
- **Visualización**: Dashboards analíticos dinámicos creados en Tableau.
- **Logro de Optimización y Calidad**: 
  - Detección y corrección de un `CROSS JOIN` crítico que inflaba las consultas de 1.000 a 1.000.000 de filas.
  - Saneamiento y limpieza de un dataset original que presentaba un **90% de fallas de integridad referencial**.
